# blindbox-figure-diorama
Convert user-uploaded 5–12cm fixed-pose Pop Mart-style blind box figures into practical miniature displays: frame scenes, 3D cases and themed platforms. We provide layered thematic renderings, full creative logic, detailed DIY tutorials and complete material lists.
# 盲盒手办微缩场景设计 Skill

> **改变世界，不改变手办。**

本 Skill 帮助**盲盒 / 潮玩手办**玩家（泡泡玛特、Dimoo、Molly、Labubu 等风格），把手中固定的收藏手办，变成一个有故事、能落地的微缩展示世界（相框 / 立体盒 / 主题地台）。

## 适用对象

- 已拥有一个**成品盲盒手办**（约 5–12cm，姿势固定，PVC / 搪胶材质）
- 想为它设计展示场景、寻找灵感、获得制作教程与材料方案
- 不想改造手办本体，只改变它所处的世界

## 核心流程

1. 分析手办真实元素（外观 / 姿态 / 物件 / 隐含故事）
2. 提取故事钩子
3. 生成 3 个高区分度主题
4. 保持手办本体 100% 一致
5. 校验展示盒尺度与物理可行性
6. 先生成完成效果图（文字 + AI 效果图）
7. 再输出完整 DIY 制作方案（灵感逻辑 + 教程 + 材料清单）

## 三大交付支柱

- **设计灵感**：从手办元素长出多个完全不同的世界观与主题。
- **制作教程**：可执行的技法与 6–10 步制作流程，含盲盒专属固定技巧。
- **材料方案**：通用材料库、平替建议与入门 / 中等 / 进阶预算分级。

## 重点质量指标

- 手办一致性 ≥ 4/5（手部 / 手持物变化属高严重度错误）
- 主题视觉差异度 ≥ 4/5
- 不擅自改变手势、姿势、手持物、脸型、底座
- 不使用"同一场景换道具"的模板化方案
- 所有场景都必须能落到真实微缩制作（能塞进展示盒）
